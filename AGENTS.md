# Dynastia Raid Tools

DRT is a small Pandaria Classic addon for shared guild, party and raid notes.

Implemented:

- minimap button and `/drt` slash command;
- main notes window with a permanent main note;
- personal notes with owner-based editing;
- quick insertion of raid markers and current group or raid players;
- note synchronization over guild, party, raid, instance and whisper addon messages;
- main note synchronization and group-creation clearing for the group leader;
- "link" button that sends the main note to raid or party chat.

The addon folder must stay named `DRT`, because the TOC and saved variables use that addon identity.
