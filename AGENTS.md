# Dynastia Raid Tools (DRT)

Этот файл - памятка для агентов, которые будут продолжать работу над аддоном. Держи здесь только актуальное состояние проекта, без старых гипотез и откатанных решений.

## Область действия и структура проекта

Этот файл относится только к аддону DRT и файлам в его каталоге. Все пути к исходникам ниже указаны относительно каталога DRT, где находится этот `AGENTS.md`.

- Основной код: `Core.lua`.
- Метаданные и список загружаемых файлов: `DRT.toc`.
- Иконка миникарты/аддона: `media/GuildCrest.tga`.
- Памятка для агентов: `AGENTS.md`.
- SavedVariables: глобальная таблица `DRTDB`. Ее сохраняет клиент WoW вне каталога аддона; пользовательские сохранения не являются исходниками проекта.

При установке каталог DRT размещается в `Interface/AddOns/DRT` внутри клиента WoW. Путь `Interface\AddOns\DRT\media\GuildCrest.tga` в Lua и TOC является игровым путем ресурса, а не путем относительно корня репозитория. Его нужно сохранять в таком виде для загрузки текстуры клиентом.

`DRT.toc` сейчас настроен на MoP/Pandaria Classic:

- `## Interface: 50504, 50503`
- `## Version: 1.0.0`
- `## SavedVariables: DRTDB`
- `## IconTexture: Interface\AddOns\DRT\media\GuildCrest.tga`

## Назначение аддона

Dynastia Raid Tools - аддон для совместной работы с заметками в текущей группе/рейде в WoW Pandaria Classic. Отдельной синхронизации со всей гильдией сейчас нет.

Основной сценарий:

- игроки создают и редактируют свои заметки;
- участники текущей группы/рейда видят заметки друг друга;
- есть общая главная заметка, синхронизируемая между участниками группы/рейда;
- главную или текущую открытую заметку можно линкануть в чат группы/рейда;
- главную заметку можно показывать отдельным маленьким окном поверх интерфейса.

## Текущее поведение UI

### Миникарта

- Мини-кнопка создается в `DRT:CreateMinimapButton()`.
- Текстура кнопки берется из константы `MINIMAP_ICON_TEXTURE`.
- Сейчас используется вырезанная бабочка гильдии на прозрачном фоне: `media/GuildCrest.tga`.
- Положение вокруг миникарты сохраняется в `DRTDB.minimap.angle`.
- ЛКМ по кнопке открывает/закрывает основное окно.
- Перетаскивание кнопки меняет угол вокруг миникарты.

### Основное окно

- Создается в `DRT:CreateMainFrame()`.
- Frame name: `DRTMainFrame`.
- Размер: `920x620`.
- Frame strata: `DIALOG`. Это важно: основное окно должно быть выше маленького окна главной заметки.
- Содержит:
  - список заметок слева;
  - редактор названия и текста;
  - кнопки `Новая`, `Удалить`, `Линкануть`, `Сохранить`, `В главную`;
  - чекбокс `Обернуть` рядом с линковкой;
  - блок быстрых вставок рейдовых меток;
  - блок быстрых вставок игроков текущей группы/рейда;
  - чекбоксы главной заметки `Показывать главную` и `Закрепить главную`.

В редакторе текста работает нативная каретка WoW `EditBox`. Сохраняй штатную обработку фокуса и кликов; не добавляй кастомную каретку, `ScrollingEdit_*`, `OnTextSet` или ручной `SetCursorPosition()` при клике без проверки необходимости и поведения в игре.

### Окно главной заметки поверх интерфейса

- Создается в `DRT:CreateMainNoteWindow()`.
- Frame name: `DRTMainNoteWindow`.
- Frame strata: `HIGH`.
- Основное окно DRT имеет `DIALOG`, поэтому при открытом основном окне popup главной заметки не должен рисоваться поверх него.
- Размер по умолчанию: `300x150`.
- Минимальный размер: `80x42`.
- Положение и размер сохраняются в `DRTDB.mainWindow`.
- В правом нижнем углу маленькая подпись `DRT`, крупной надписи `Главная заметка` быть не должно.
- Чекбокс `Показывать главную` включает/выключает окно.
- Чекбокс `Закрепить главную` запрещает перетаскивание/ресайз и отключает перехват мыши окном.
- Текст главной заметки обновляется после сохранения, очистки, переноса другой заметки в главную и входящей синхронизации.
- Рейдовые метки в popup показываются иконками через `FormatTextForDisplay()`.

## Данные и SavedVariables

`EnsureDB()` нормализует структуру:

- `DRTDB.notes` - таблица заметок.
- `DRTDB.main.text`, `DRTDB.main.updated`, `DRTDB.main.owner` - главная заметка.
- `DRTDB.minimap.angle` - позиция мини-кнопки.
- `DRTDB.wrapLinkedNote` - состояние чекбокса `Обернуть`.
- `DRTDB.mainWindow.enabled`, `locked`, `width`, `height`, `left`, `top` - состояние окна главной заметки.

Правило хранения заметок:

- свои сохраненные заметки являются постоянными;
- чужие заметки нужны только для текущей группы/рейда и не должны жить вечно;
- удаленные заметки не должны храниться как постоянные `deleted = true` tombstone-записи.

Сейчас чистка реализована так:

- `DRT:PruneForeignNotes()` удаляет старые/чужие/удаленные записи из `DRTDB.notes`;
- при `/reload` вне группы удаляются все чужие заметки;
- при `/reload` внутри группы/рейда остаются заметки текущих участников, а заметки старых игроков удаляются;
- при выходе из группы/рейда чужие заметки удаляются;
- при изменении состава группы/рейда удаляются заметки игроков, которых больше нет в составе.

WoW записывает SavedVariables аддона в файл `DRT.lua` в каталоге сохранений учетной записи при `/reload` или выходе из игры. Очистка в памяти не обязана мгновенно появиться на диске. Этот файл не следует путать с исходником `Core.lua`.

## Модель заметок

Ключ заметки:

- `NoteKey(owner, id)`
- разделитель: `NOTE_KEY_SEPARATOR = "\030"`

Поля обычной заметки:

- `id`
- `owner`
- `title`
- `body`
- `updated`
- `localOnly` только для новых еще не сохраненных заметок

`deleted` допускается только во временном delete-payload при отправке удаления. Постоянно хранить `deleted = true` или `deleted = false` в `DRTDB.notes` не нужно.

Главная заметка не лежит в `DRTDB.notes`; она хранится отдельно в `DRTDB.main`.

## Синхронизация

Addon message prefix: `DRT`.

Сообщения режутся на чанки:

- формат чанка: `C|id|index|total|part`;
- размер чанка: `CHUNK_SIZE = 170`;
- сборка входящих чанков живет в `DRT.incomingChunks`;
- отправка идет через очередь `DRT.outgoingQueue`, чтобы не спамить API.

Каналы синхронизации:

- только текущая группа/рейд/instance group;
- `GetGroupChannel()` выбирает `INSTANCE_CHAT`, `RAID` или `PARTY`;
- `GUILD` намеренно не используется, чтобы заметки не возвращались вне рейда и не становились глобальными.

Payload kinds:

- `REQ` - запрос синхронизации.
- `NOTE` - одна заметка или временный delete-payload.
- `OWNER` - снимок актуальных id заметок владельца.
- `MAIN` - главная заметка.

`DRT:SendAllNotes(channel, target)` отправляет:

1. Только свои сохраненные заметки (`IsOwnNote(note)`, не `localOnly`, не `deleted`).
2. `OWNER` со списком актуальных id своих заметок.
3. `MAIN` с главной заметкой.

`OWNER` важен: он заменяет старую схему вечных tombstone-записей. Если другой клиент хранит старую заметку владельца, которой больше нет в `OWNER`, он удаляет ее.

Входящие чужие заметки принимаются только если `owner` является текущим участником группы/рейда. Это защищает от старых заметок, прилетевших не к месту.

## Главная заметка

- Всегда существует отдельно от списка обычных заметок.
- При создании группы/рейда лидер очищает главную заметку через `DRT:ClearMainNote(true)`.
- Любую обычную заметку можно перенести в главную кнопкой `В главную`.
- Главная синхронизируется через `MAIN` payload.
- `DRT:UpdateMainNoteWindow()` обновляет отдельное popup-окно главной.

## Линковка в чат

- Кнопка `Линкануть` отправляет текущую открытую заметку, а не всегда главную.
- `DRT:GetCurrentLinkText()` выбирает текст текущей активной заметки.
- `DRT:LinkCurrentNote()` отправляет в `RAID` или `PARTY`.
- Если игрок не в группе/рейде, линковка пишет предупреждение и ничего не отправляет.
- Рейдовые метки в тексте вида `{rt1}`-`{rt8}` конвертируются в локализованные chat tokens через `FormatTextForChat()`.
- Чекбокс `Обернуть` добавляет при линковке строки:

```text
<<<<<<<<<<<<<<<<<<<<<<<<<
текст заметки
>>>>>>>>>>>>>>>>>>>>>>>>>
```

## Быстрые вставки

Рейдовые метки:

- `RAID_MARKERS` хранит текстуры и токены.
- На старте токены заменяются на локализованные `_G["RAID_TARGET_" .. i]`, если они доступны.
- Клик по метке вставляет токен в тело заметки.

Игроки:

- `DRT:GetRoster()` собирает текущий рейд/пати/игрока.
- `DRT:RefreshPlayerButtons()` рисует кнопки игроков.
- ЛКМ вставляет имя с пробелом.
- `Shift+ЛКМ` вставляет имя без пробела.

## Команды

Slash commands:

- `/drt`
- `/дрт`

Подкоманды:

- `/drt sync` - запросить синхронизацию.
- `/drt clear` - очистить главную заметку и разослать обновление.
- без подкоманды - открыть/закрыть основное окно.

Для тестирования ошибок в игре:

```text
/console scriptErrors 1
/reload
```

## Проверки перед релизом

Минимальный ручной чеклист:

- `/reload` без ошибок Lua.
- Мини-иконка около карты показывает бабочку без щита/квадрата.
- Основное окно открывается с миникарты и через `/drt`.
- Нативная каретка в редакторе текста видна и клики по тексту работают нормально.
- Создание, сохранение и удаление своей заметки.
- После удаления заметка пропадает и не остается в SavedVariables как `deleted = true`.
- Синхронизация заметок в рейде/группе.
- `/reload` внутри рейда не удаляет заметки текущих участников.
- Выход из рейда удаляет чужие заметки локально.
- `/reload` вне рейда не возвращает чужие заметки.
- Линковка текущей активной заметки в чат.
- `{rt1}`-`{rt8}` отображаются рейд-метками в чате.
- Чекбокс `Обернуть` добавляет строки из `<` и `>`.
- Окно главной заметки показывается, двигается, ресайзится до маленького размера и закрепляется.

## Технические замечания для агентов

- Версия релиза: `1.0.0`. При изменении версии согласованно обновлять `VERSION` в `Core.lua` и `## Version` в `DRT.toc`.
- Сохранять UTF-8 для русскоязычных строк интерфейса и документации.
- Проверять изменения через `git diff --check` из каталога репозитория DRT и ручные проверки в WoW. Проверка вне игры не подтверждает работу WoW API, интерфейса и сетевой синхронизации.
- SavedVariables - пользовательские данные вне проекта. Не удалять и не редактировать их без явного запроса пользователя.
- Изменения аддона ограничивать его каталогом; расположение клиента и инструменты конкретной машины не являются частью проекта.
