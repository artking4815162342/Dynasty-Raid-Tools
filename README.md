# Dynastia Raid Tools (DRT)

Аддон заметок для WoW Pandaria Classic. Версия 2.0.0.

## Установка

Поместите каталог `DRT` в `Interface/AddOns` клиента и включите аддон в списке модификаций. Для работы нужны `DRT.toc`, `Notes.lua`, `Core.lua` и каталог `media`. Внешние библиотеки не требуются.

Открыть окно можно кнопкой у миникарты, командой `/drt` или `/дрт`.

## Заметки

- У каждой заметки есть владелец. Свои заметки можно создавать, редактировать и удалять; чужие доступны для просмотра.
- «Шарить» включено по умолчанию. После сохранения заметка становится доступна участникам текущей группы/рейда с DRT.
- Выключение «Шарить» оставляет заметку только у владельца и отправляет остальным обновлённый список без неё. Переключение действует на сохранённый текст; черновик не отправляется.
- Личные заметки сохраняются по персонажам. Выход из группы, reload и вход другим персонажем их не удаляют.
- Чужие заметки хранятся только в памяти. После reload они вновь загружаются от участников, после выхода из группы исчезают.
- Общей заметки больше нет.

«Показывать поверх UI» выводит выбранную заметку в маленьком окне. «Закрепить окно» фиксирует его положение и отключает перехват мыши. Можно показывать как свою, так и чужую расшаренную заметку.

«Линкануть» отправляет сохранённый текст текущей заметки в чат группы/рейда, включая случайную группу подземелья. Это ручная публикация: кнопка доступна и для приватной заметки. «Обернуть» добавляет строки из `<` и `>`. Рейдовые метки и имена участников вставляются кнопками редактора.

`/drt sync` повторно запрашивает заметки участников. Несохранённые изменения сохраняются при переключении заметок в текущей сессии; перед reload нужно нажать «Сохранить».

## Обновление с 1.0.0

Все участники должны обновиться до 2.x: сетевой протокол 1.x несовместим с новой моделью.

Старые заметки текущего персонажа автоматически переносятся в его личный профиль. Неоднозначные старые записи сохраняются в архиве внутри SavedVariables, чтобы не потерять заметки других своих персонажей. При входе соответствующим персонажем его записи импортируются. Архив не отправляется другим игрокам и не появляется в обычном списке.

Непустая прежняя общая заметка превращается в обычную приватную «Сохранённую заметку». Положение маленького окна сохраняется; для показа нужно выбрать заметку заново.

## Ограничения

Сетевой снимок ограничен 512 заметками, 64 КиБ текста на заметку и 512 КиБ после кодирования. Слишком большой расшаренный текст не сохраняется с потерей данных: аддон выдаёт сообщение и оставляет введённый текст в редакторе. Его можно сохранить приватно. Большие наборы заметок передаются постепенно, поэтому обновление списка может занять время.

## Проверка разработки

Из корня проекта:

```text
python -m pip install --target .test-deps lupa==2.8
python tests/run.py
git diff --check
```

Тесты используют Lua 5.1 и имитацию WoW API. Каталоги `.test-deps` и `tests` не требуются для запуска аддона в игре. Результаты ревью и границы проверки описаны в [REVIEW.md](REVIEW.md).

После установки проверить в игре `/console scriptErrors 1`, `/reload`, каретку, маленькое окно, обмен между двумя игроками, отзыв шаринга и сохранность своих заметок после выхода из рейда.
